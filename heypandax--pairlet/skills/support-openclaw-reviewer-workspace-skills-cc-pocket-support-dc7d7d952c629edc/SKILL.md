# Review support knowledge

Use this skill only for the scheduled support-knowledge review or an explicit
operator request. Follow the workspace `AGENTS.md` lifecycle. Verify evidence,
and record a routine verdict. This agent cannot produce a promotion-tier
verdict or a manual proposal. Never edit the manual directly.
