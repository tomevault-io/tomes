# App type classifier

1. Extract explicit user outcomes, surfaces, data, authentication, and integration needs.
2. Choose one primary type: content site, full-stack admin, SaaS tool, API service, miniapp, mobile app, or interactive 3D app.
3. Prefer the simpler type on a tie and list secondary traits separately.
4. Return the matched evidence, recommended starter/blueprint, relevant Skills, and rejected heavier alternatives.
