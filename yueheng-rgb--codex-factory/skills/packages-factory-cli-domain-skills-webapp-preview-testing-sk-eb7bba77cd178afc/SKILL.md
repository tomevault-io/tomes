# Web app preview and testing

- Confirm one documented install/start command works from a clean state with an environment template.
- Exercise the real browser path: load, core CTA, validation failure, successful submit, navigation, data refresh, and permission denial.
- Check loading, empty, error, success, duplicate submission, and retry states at 375, 768, and 1440 pixel widths when relevant.
- Record exact commands, URLs, assertions, screenshots/traces when useful, exit codes, and observed console/network failures.
- Do not claim PASS from source inspection alone when the acceptance method requires runtime behavior.
