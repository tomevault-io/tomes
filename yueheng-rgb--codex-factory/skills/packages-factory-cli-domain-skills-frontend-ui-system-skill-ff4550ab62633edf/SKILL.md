# Frontend UI system

- Implement loading, empty, error, and success states for every data region.
- Implement idle, submitting, success, and failure states for every mutation; prevent duplicate submission and retain failed input.
- Define a restrained color, type, spacing, and component system suited to the product rather than generic AI gradients or emoji decoration.
- Verify keyboard use, focus, labels, contrast, responsive widths, long text, and error recovery.
- Keep mobile touch targets at least 44 by 44 CSS pixels and prioritize the primary user action.
