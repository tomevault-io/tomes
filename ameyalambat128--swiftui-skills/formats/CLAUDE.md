# swiftui-skills

> - Do not use Tailwind `leading-*` utilities directly. Line-height lives in the type tokens.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/swiftui-skills/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# AGENTS

## Web

- Do not use Tailwind `leading-*` utilities directly. Line-height lives in the type tokens.
- Do not use ad-hoc Tailwind tracking values. If tracking must be set directly, use only `tracking-normal`, `tracking-tight`, or `tracking-tighter`.
