# Review a pull request

Read the diff and the surrounding code. Identify concrete regressions
introduced by the change and explain the inputs that trigger each one.
Use [the checklist](references/checklist.md) to guide the review.

Report actionable findings with file locations. If no issues are found,
say so and state which behavior was verified.
