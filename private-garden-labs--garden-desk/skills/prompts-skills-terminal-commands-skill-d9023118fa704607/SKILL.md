Use `bash` for one-step BusyBox commands; `python` for parsing or multiple steps. `list` returns the folder tree.

Example: `find /source -iname "*.csv"`.

Check exit code and output. Empty search output means no match. Shell text search cannot read DOC, DOCX, PDF, or XLSX content.
