Include scope, cited findings, gaps, actions, and limits. Use source figures, not draft figures. Add no scores, unsupported risk labels, or color-only meaning.

Default to DOCX; use PDF on request. Load the format skill. In its final check, include headings, tables, and citations. State that visual layout needs human review.
