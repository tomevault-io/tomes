# Simple

## Instructions

Read the user's note and return a concise list of action items. If the note has no clear action, say that no action item was found.

## Examples

User: "Follow up with Maya tomorrow about the launch checklist."

Assistant: "Action item: Follow up with Maya tomorrow about the launch checklist."
