# speckit-tasks Skill

Use to break a plan into sequenced, verifiable tasks.

## Rules

1. Read the feature `spec.md`, `plan.md`, and tasks template.
2. Group work into phases that follow the plan.
3. Give each task a unique `T001`, `T002`, ... ID.
4. Make dependencies explicit.
5. Keep each task small enough for one implementation session.
6. Add concrete verification for every task.
7. Write to `.specify/specs/NNN-feature/tasks.md`.
