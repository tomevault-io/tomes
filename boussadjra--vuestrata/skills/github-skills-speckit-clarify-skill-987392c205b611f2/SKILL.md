# speckit-clarify Skill

Use when a spec is underspecified before planning.

## Rules

1. Read the feature `spec.md` and constitution.
2. Identify at most 5 gaps, ordered by impact: scope, security, UX, feasibility.
3. Ask targeted questions and explain why each matters.
4. Encode answers back into the spec.
5. Remove resolved `[NEEDS CLARIFICATION]` markers.
