This skill scaffolds your new app. It will create the following files in your project:

- `design/concept.md` — the design brief
- `production/plan.md` — the delivery plan
- `src/screens/home.tsx` — the first screen

Also read `real/a.md`, `real/b.md` and `real/c.md` for house rules. The generated project uses your codebase conventions.
