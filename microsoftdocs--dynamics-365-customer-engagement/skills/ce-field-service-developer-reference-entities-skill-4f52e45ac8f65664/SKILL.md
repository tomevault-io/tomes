# Business Skill (Skill) table/entity reference (Microsoft Dynamics 365 Field Service)

Records of instructions, scripts, and resources that agents can discover and use to do things more accurately and efficiently.

> [!NOTE]
> The Microsoft Dynamics 365 Field Service Business Skill (Skill) table extends the [Microsoft Dynamics 365 Business Skill (Skill) table](/dynamics365/developer/reference/entities/skill).



## Customized columns/attributes

Microsoft Dynamics 365 Field Service modifies the definition of columns/attributes defined in other solutions. Listed by **SchemaName**.
